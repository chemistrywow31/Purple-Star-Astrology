# 紫微斗數課程概念查詢指南

- 概念檢索：[[紫微斗數課程-概念檢索-索引]]
- 標準概念：[[紫微斗數課程-標準概念索引]]
- 別名路由：[[紫微斗數課程-別名查詢路由]]

> [!note] 保證邊界
> 保證等級是 **pragmatic**；引用方針是 **transcript-primary**，講義僅作 auxiliary evidence。

## Deterministic retrieval order

1. 對 query 做 NFKC、trim 與連續空白折疊；先在 [[紫微斗數課程-別名查詢路由#Canonical／alias query routes|別名查詢路由]] 做完整字串 match。
2. 收集 route 列出的全部 canonical groups；若同一 alias 路由多組，保留全部，不以第一筆或字面相似度消歧。
3. 合併 route 的 `All occurrence IDs`，依 ID 數字升冪去重；再由 index 的 `Lessons` 聚合全部 lesson，不漏同課多 occurrence。
4. 依 ID 對應 Lesson ID 的季別，從 [[紫微斗數課程-概念檢索-索引#季別定位表|季別定位表]] 開啟對應的「紫微斗數課程-第NN季定位表」逐 ID 查列，先回報 lesson ID／title，再引用 `Transcript chapter`＋`Transcript anchor`＋`Raw range` 作 primary citation。
5. `Transcript status=missing-lesson|missing-concept` 時明寫「逐字稿無對應資料」；handout-only 的 S01E000 不假造 primary citation。
6. 再引用 `Handout file`＋`Handout chapter`＋`Handout page` 作 auxiliary citation；`Handout status=missing-lesson|missing-concept` 時明寫「講義無對應資料」。
7. canonical／alias route 零命中時回覆 `NO_DATA: concept index 無 canonical／alias match`，不搜尋 raw unit files來猜補。

## Citation shape

- Primary：`{Lesson ID}｜{Lesson title}｜逐字稿 {chapter}｜{anchor}｜{raw range}`。
- Auxiliary：`講義 {file}｜{chapter}｜{page}`；僅在 `available` 時輸出。
- No-data：逐來源明示 `逐字稿無對應資料`／`講義無對應資料`，禁止用另一來源補造 locator。

## Assurance boundary

- 結構保證是全量：94 lessons、93 transcript files、90 handout PDFs、1,221 occurrence rows、ID／multiset／source path／locator schema 均由 validator 全量檢查。
- 語義保證是 pragmatic sampling：沿用各 accepted unit 的 known-regression、direct-source checks 與 deterministic representative samples；不宣稱 1,221 rows 或所有 PDF pages 已做 exhaustive semantic proof。
- Falsification condition：任一查詢結果的 transcript raw 語義或 handout page 與概念不符，即建立定點 regression case、由上游 owner 修復 lesson artifact，再全量重建本 corpus。

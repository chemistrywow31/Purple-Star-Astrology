# 十二宮位情境配對練習

上一站：[[四化與十天干查表練習]]｜入口：[[紫微斗數練習與工具-索引]]｜主題：[[紫微斗數十二宮位與身宮-索引]]、[[十二宮位與轉宮法入門]]｜護欄：[[紫微斗數學習安全邊界]]｜下一站：[[紫微斗數綜合案例練習]]

## 一句話先懂

宮位先分觀察範圍，再用三方四正避免單宮定論。

## 先備知識

- 知道十二宮是不同觀察入口，不是十二個彼此隔絕的答案。
- 知道身宮不是第十三宮，完整閱讀仍須三方四正。

## 學習目標

1. 把虛構情境配到本課支持的宮位範圍。
2. 區分財務四宮與社會圈四宮的不同焦點。
3. 遇到健康、關係、性／生育與財務題時主動寫出限制。

## 自足小抄

| 宮位 | 本課入門觀察範圍 |
|---|---|
| 命宮 | 整體觀察起點 |
| 兄弟宮 | 手足、合作 |
| 夫妻宮 | 伴侶、偏好、關係與時間層 |
| 子女宮 | 子女、生育／性、學生、寵物 |
| 財帛宮 | 現金、理財方式 |
| 疾厄宮 | 傳統身體脈絡 |
| 遷移宮 | 外地、陌生人、遠方環境 |
| 交友宮 | 朋友、部屬、同事、工具 |
| 官祿宮 | 工作形式、主管 |
| 田宅宮 | 留存資產、居所、家庭基地 |
| 福德宮 | 享受、心理／情緒語境、收入來源 |
| 父母宮 | 父親、長輩、主管、機構、公告 |

## 白話比喻

宮位像圖書館的分類區：同一問題可能要走訪幾區，不能只看一個書架。這只是記憶入口，不是命理或現實因果的證據。

## 逐步理解

1. 把情境中的名詞換成「正在觀察什麼」。
2. 先選最直接的宮位，再寫出容易混淆的宮位。
3. 用財務四分法或社會圈四分法核對。
4. 加上「仍須三方四正」與高風險限制。
5. 若問題超出索引範圍，答案寫資料不足。

## 宮位情境分類（VQ）

### 題組一：財務焦點

把以下虛構觀察配到主要入口：A 手上現金如何管理；B 已留存的不動產／家庭基地；C 收入來源與享受方式；D 與朋友直接投資的互動。

<details>
<summary>逐步揭答</summary>

- A 財帛宮：現金與理財方式。
- B 田宅宮：留存資產、居所與家庭基地。
- C 福德宮：收入來源與享受語境。
- D 交友宮：朋友／同事互動，在本課財務切分中也涵蓋與朋友直接投資。

這只是分類入口，不能因此提供投資建議、判定財富或保證收益。

</details>

### 題組二：社會圈焦點

把以下虛構觀察配到主要入口：A 外地陌生環境；B 朋友與部屬；C 手足與合作夥伴；D 學生與晚輩。

<details>
<summary>逐步揭答</summary>

A 遷移宮、B 交友宮、C 兄弟宮、D 子女宮。這些是本課入門分類，人物角色可能重疊，仍須題目脈絡與三方四正；不能靠宮位替真人貼關係標籤。

</details>

### 題組三：高風險邊界

虛構問題問：「疾厄宮能否診斷某人有沒有疾病？」

<details>
<summary>逐步揭答</summary>

不能。疾厄宮在此只作傳統身體語境；醫療問題要由合格醫療專業與現實檢查處理。夫妻宮、子女宮、福德宮與財帛相關問題也不能取代關係、心理或財務專業判斷。

</details>

- **看什麼**：題組把最容易混淆的財務與社會圈宮位並排比較。
- **怎麼看**：先辨認觀察焦點，再選主要入口，最後補三方四正與限制。
- **不能推出什麼**：配對不能診斷疾病、預測關係、生育、職涯、財富或心理狀態。

## 虛構例子

虛構學員小辰看到「主管」就只答官祿宮。重做時，他分清楚：若觀察工作形式／主管可從官祿宮切入；若觀察機構公告或長輩脈絡，父母宮也可能是入口。題目未給更多條件，不能再延伸。

## 常見誤解

> [!warning] 常見誤解
> - 財帛宮等於全部財富：本課把現金、留存資產、收入來源與朋友投資分開。
> - 官祿宮能決定唯一職業：它只提供工作形式與主管的觀察入口。
> - 身宮是第十三宮：身宮是另一閱讀層，不是新增一宮。

## 自我檢核

1. **「外地陌生人」優先配哪一宮？** 遷移宮；仍須三方四正，不能推出旅行事件。
2. **「留存資產」優先配哪一宮？** 田宅宮；不能作資產估值或理財建議。
3. **命宮可否用獨立專題補充？** `INSUFFICIENT_DATA: 本課無獨立命宮專題`；只能依 I2、I10 作整體觀察起點，不能新增教義。

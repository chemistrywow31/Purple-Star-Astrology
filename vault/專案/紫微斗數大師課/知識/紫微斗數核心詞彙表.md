# 紫微斗數核心詞彙表

上一站：[[紫微斗數綜合案例練習]]｜來源邊界：[[紫微斗數來源地圖與待考索引]]｜下一站：[[紫微斗數全課自我測驗]]

## 一句話先懂

同一術語先翻成白話，再標出最容易誤會的邊界。

## 先備知識

- 知道本表整理的是本課索引用語，不是所有流派的統一定義。
- 查詞後仍要回到對應主題筆記看完整條件。

## 學習目標

1. 用高中生能理解的話解釋核心術語。
2. 在每個詞旁辨認「勿混淆」項。
3. 從詞彙表回到八個主題入口與來源地圖。

## 自足小抄

查詞三步：**找術語→讀白話→讀勿混淆**。若詞彙涉及待考、單一來源或庚年版本，就轉到[[紫微斗數來源地圖與待考索引]]，不要自行補完。

## 白話比喻

詞彙表像地圖圖例：先說符號代表什麼，也提醒哪兩個圖示不能當成同一件事。這只是記憶工具，不是命理有效性的證據。

## 逐步理解

1. 先按「結構／星曜／四化／宮位／證據」分類。
2. 用白話欄理解最低限度含義。
3. 用勿混淆欄阻止過度推論。
4. 點入對應主題 MOC 查看條件與來源卡。

## 術語／白話／勿混淆（VM）

| 術語 | 白話 | 勿混淆 |
|---|---|---|
| 命盤 | 課程安排星曜、宮位與時間資訊的閱讀結構 | 不是人生資料庫或科學預測模型 |
| 本命 | 課程的基本時間層 | 不等於一生必然不變 |
| 大限 | 本命之後的期間閱讀層 | 不等於期間內事件保證 |
| 流年 | 更細的年度閱讀層 | 不等於年度預言 |
| 主星 | 判讀中先辨認的核心星曜 | 單星不能獨立定論 |
| 輔星 | 與主星合看的支援／干擾條件 | 「輔」不代表次要到可忽略 |
| 雜曜 | 課程中的其他小星條件 | 不能脫離主星與宮位放大解讀 |
| 空宮借對宮 | 空宮時參考對宮主星的課程方法 | 不代表把對宮全部原封不動搬來 |
| 三方四正 | 把本宮與相關宮位一起看的結構 | 不是只看單一宮位 |
| 身宮 | 另一閱讀層 | 不是第十三宮 |
| 廟旺落陷 | 課程描述星曜顯著／狀態的用語 | 不是人格或吉凶分數 |
| 雙星強弱 | 比較兩星在題目條件下哪側較顯著 | 不是固定相加公式 |
| 化祿 | 增加、金錢、緣分等象意 | 不等於全吉或一定有錢 |
| 化權 | 權力、控制、欲望與責任成本 | 不等於一定掌權 |
| 化科 | 名聲、可見度、考試、聰明等象意 | 不等於一定成功 |
| 化忌 | 麻煩、缺口、欲望、壓力等象意 | 不等於全凶或災難必發 |
| 十天干四化 | 依天干查祿權科忌星曜的本課表格 | 不是跨流派唯一版本 |
| 庚年雙版本 | 庚干四化的 A、B 兩套對應 | 不能擇一冒充唯一正解 |
| 十二宮 | 十二種入門觀察範圍 | 一宮不能包辦整個問題 |
| 財帛宮 | 現金與理財方式的入口 | 不等於全部財富或投資建議 |
| 田宅宮 | 留存資產、居所與家庭基地的入口 | 不等於只看房產價值 |
| 疾厄宮 | 傳統身體脈絡的入口 | 不是疾病診斷 |
| 待考 | 來源文字或版面仍不足以形成教義 | 不是可自由猜補的空格 |
| 單一來源 | 只有一側課程材料支持 | 不等於已跨來源確認 |
| 來源卡 | 筆記末端的索引與證據強度摘要 | 不直接連到 raw 或原始個資 |

- **看什麼**：每列第三欄主動阻止最常見的錯誤等號。
- **怎麼看**：若只記得白話卻答不出「勿混淆」，就還沒完成查詞。
- **不能推出什麼**：詞彙定義不能證明命理有效，也不能替真人作預測或專業判斷。

## 虛構例子

虛構學員小沐查「化忌」，先寫「麻煩、缺口、欲望、壓力」，再抄下「不是全凶或災難必發」。他若要答題，還要回到時間層、星曜、宮位與三方四正。

## 常見誤解

> [!warning] 常見誤解
> - 只背白話欄：缺少「勿混淆」就容易變成斷語。
> - 把不同流派都當成本課表格：庚年已顯示版本會分歧。
> - 把待考當成冷門知識：待考代表目前不得使用。

## 自我檢核

1. **身宮是不是第十三宮？** 不是；它是另一閱讀層，不能新增宮位。
2. **單一來源是否等於錯誤？** 不等於錯誤，但證據較弱，不能寫成跨來源共識。
3. **化祿可否直接翻成好運？** 不可；它有增加、金錢、緣分等課程象意，仍需條件。

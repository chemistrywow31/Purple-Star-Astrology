# 十四主星辨識練習

上一站：[[紫微斗數新手判讀工作紙]]｜入口：[[紫微斗數練習與工具-索引]]｜主題：[[紫微斗數十四主星-索引]]、[[十四主星的閱讀方法]]｜護欄：[[紫微斗數學習安全邊界]]｜下一站：[[雙星強弱判讀練習]]

## 一句話先懂

先用關鍵字辨認主星，再立刻補上「不能單星定論」。

## 先備知識

- 知道十四主星是辨識起點，不是人格標籤。
- 願意在每個答案後補看宮位、四化、輔星與三方四正。

## 學習目標

1. 將十四組課程關鍵字配對到正確主星。
2. 區分容易混淆的資源、行動、才藝、照護與表達概念。
3. 為每次配對寫出條件與不可推論項。

## 自足小抄

十四主星：紫微、天府、天機、太陰、天同、天梁、七殺、破軍、貪狼、廉貞、天相、太陽、武曲、巨門。關鍵字是入口；完整閱讀還要合看其他盤面條件。

## 白話比喻

把主星關鍵字想成書背上的分類標籤：它能幫你找書，卻不能代替整本內容。這只是記憶比喻，不是星曜證據。

## 逐步理解

1. 先讀屬性卡，不看答案。
2. 找出最有辨識力的詞，例如「資源庫」與「策略變動」。
3. 配對後說出一個容易混淆的鄰近概念。
4. 最後加一句：「仍要看宮位、四化、輔星與三方四正。」

## 屬性卡配對（VQ）

### 第一組：請配對六顆星

| 卡片 | 課程關鍵字 |
|---|---|
| A | 領導、穩定、尊貴感 |
| B | 資源庫、分配、保守穩定 |
| C | 思考、策略、變動、多元 |
| D | 內在、累積、夜晚、土地 |
| E | 享樂、純真、情緒、慵懶 |
| F | 長者、保護、照護、教育 |

<details>
<summary>逐步揭答</summary>

1. A 紫微：先抓「領導／尊貴」；但不能推出權力或成就。
2. B 天府：先抓「資源庫／分配」；但不能推出一定富有。
3. C 天機：先抓「思考／策略／變動」；但不能推出一定多變或行動快。
4. D 太陰：先抓「內在／累積／夜晚」；但不能推出性別或情緒診斷。
5. E 天同：先抓「享樂／純真／情緒」；但不能推出幼稚或逃避責任。
6. F 天梁：先抓「長者／保護／照護」；但不能推出必然逢凶化吉。

每張卡仍需宮位、四化、輔星與三方四正才可進一步閱讀。

</details>

### 第二組：請配對八顆星

| 卡片 | 課程關鍵字 |
|---|---|
| G | 直接、果斷、行動 |
| H | 改變、消耗、突破 |
| I | 才藝、社交、欲望、桃花 |
| J | 規則、外交、精神欲望 |
| K | 連結、服務、印、環境 |
| L | 公開、熱情、注意力、領導 |
| M | 財務、執行、剛硬 |
| N | 言語、爭議、洞察、暗 |

<details>
<summary>逐步揭答</summary>

G 七殺、H 破軍、I 貪狼、J 廉貞、K 天相、L 太陽、M 武曲、N 巨門。

- 配對依據是 I4 的課程關鍵字。
- 「桃花」不能用來斷定外貌、性傾向或關係事件；「財務」不能推成投資建議；「爭議」不能推成犯罪或衝突必然發生。
- 若題目沒有宮位、四化、輔星與三方四正，答案只到辨識為止。

</details>

- **看什麼**：同一張卡刻意放入多個同群關鍵字，不靠單一字猜星。
- **怎麼看**：先配最鮮明的概念，再用其餘詞交叉核對，揭答後補寫限制。
- **不能推出什麼**：配對成功不能證明人格、職業、健康、財富或關係結果。

## 虛構例子

虛構卡片寫「資源庫、分配、保守穩定」。小晴先答天府，再寫「若要解讀某宮，仍需該宮、四化與三方四正；不能因此說某人一定有錢」。這才是完整練習答案。

## 常見誤解

> [!warning] 常見誤解
> - 紫微等於一定當領導：關鍵字不是職位保證。
> - 武曲等於會賺錢：財務意象不是財富預測。
> - 貪狼等於感情事件：桃花詞彙不能取代關係現實。

## 自我檢核

1. **「策略、變動」配哪顆星？** 天機；仍要看其他條件，不能推出一定善變。
2. **「改變、消耗、突破」配哪顆星？** 破軍；不能推出必然破壞或發生重大事件。
3. **為什麼答案後要寫限制？** 因為單星只提供象意候選，不能獨立定論。

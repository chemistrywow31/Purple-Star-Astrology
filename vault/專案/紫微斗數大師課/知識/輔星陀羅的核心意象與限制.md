# 輔星陀羅的核心意象與限制

## 一句話先懂

> [!abstract] 白話摘要
> 陀羅用「緩慢、拖延、執著」修飾主星節奏，不等於人格或結果已被決定。

## 先備知識與學習目標

- 先備：[[紫微斗數輔星-索引]]、[[輔星如何改變主星表現]]。
- 目標：用條件語言理解陀羅的「磨」，並與 [[輔星擎羊的核心意象與限制]] 的直接、衝動形成對照。

## 自足小抄

- 教材標籤：北斗、刑傷、陰金，講義另載化氣為忌。
- 核心方向：緩慢、拖延、執著。
- 「磨」：反覆停留、打磨或推進較慢的記憶比喻。
- 限制：外貌與宮位推論都不可脫離非必然聲明。

## 白話比喻

陀羅像在粗砂紙上慢慢磨一塊木頭：可能拖久，也可能反覆加工。這個比喻不代表每次緩慢都有相同原因，更不是性格證明。

## 逐步理解

1. 先以「緩慢／拖延／執著」辨認本課的陀羅方向。
2. 放在主星旁時，問原有表現是否更反覆、更難快速放下或更願意長時間打磨。
3. 同一個「慢」可能被解讀成阻滯，也可能只是持續；I7 沒有提供固定好壞公式。
4. 外貌、人物與宮位描述都必須保留非必然限制，不能從陀羅一星推出現實結論。

## 圖解：陀羅條件卡

| 欄位 | 內容 |
|---|---|
| 核心詞 | 緩慢、拖延、執著 |
| 課內分類 | 北斗、刑傷、陰金、化氣為忌 |
| 讀主星時問 | 原有方向是否呈現反覆打磨或難以迅速轉向？ |
| 對照 | 擎羊偏直接；陀羅偏慢與磨 |
| 停止線 | 不由單星判定外貌、人格或失敗 |

### 圖說三問

- **看什麼**：卡片把陀羅的節奏詞與擎羊的直接詞並列。
- **怎麼看**：只比較表現節奏，再回到主星、宮位與其他條件。
- **不能推出什麼**：不能推出某人一定拖延、固執、失敗，或具有特定外貌。

## 虛構例子

虛構練習卡的主星方向是「喜歡分析選項」。加入陀羅後，可提出「分析過程可能更反覆或更久」；若現實資料顯示此人快速決定，就必須修正閱讀，而不是硬套星曜詞。

## 常見誤解

> [!warning] 執著不只一種結果
> 不能把執著直接翻譯成毅力或缺點；兩種評價都需要情境證據，本課沒有授權單星定性。

## 自我檢核

1. **陀羅與擎羊的第一層差異是什麼？** 陀羅偏緩慢與磨，擎羊偏直接與衝動；這不能推出誰比較吉或比較凶。
2. **看到陀羅能判定外貌嗎？** 不能。來源明示外貌推論不可脫離非必然聲明，也需其他條件。

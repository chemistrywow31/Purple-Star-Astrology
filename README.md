# 紫微斗數學習資料庫與互動課程

本 repository 包含兩個可獨立使用的交付物：

- `vault/`：可直接以 Obsidian 開啟的紫微斗數專案知識庫。
- `interactive-course/`：以互動方式整理學習路徑、概念探索與自我複習的網站原始碼。

## 網站建置

在本機安裝相容的 Node.js 後執行：

```bash
cd interactive-course
npm ci
npm run build
```

## 存取與使用邊界

互動網站的 Sites 部署維持私有，未在本 repository 公開存取連結、帳號資訊或發布權限。

本內容用於紫微斗數的文化脈絡與學習討論，不構成醫療、法律、財務、心理或其他專業建議；亦不應用於對個人作出決定論、歧視性或高風險判斷。
